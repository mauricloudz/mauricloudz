### 🤖 Cómo trabajo con IA

- **Documentación primero.** Requisitos, arquitectura y decisiones técnicas por escrito antes de escribir código.
- **Agentes con contexto.** Cada proyecto tiene sus propios agentes y skills de IA que conocen su arquitectura y sus reglas.
- **Calidad no negociable.** Pruebas automatizadas, CI/CD y revisión de seguridad en cada entrega.
